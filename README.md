# スカイライン・テクノロジーズ 企業サイト

架空のソフトウェア開発会社「スカイライン・テクノロジーズ」のコーポレートサイトです。
HTML・CSS・JavaScript を `index.html` 1ファイルにまとめた1ページ構成で、ビルドやサーバーは不要です。

> ※ 社名・代表者名・所在地・実績などの内容はすべて架空のものです。

## サイトの概要

| セクション | 内容 |
| --- | --- |
| ヘッダー | ロゴ・ナビゲーション（スマホではハンバーガーメニュー） |
| お知らせ欄 | ナビゲーション下に最新のお知らせを約4.5秒ごとに切り替え表示 |
| ヒーロー | 夜空と街並みのイラストを背景にしたキャッチコピー |
| 私たちについて | 会社紹介と実績の数字（カウントアップ表示） |
| 事業内容 | クラウド開発、AI・データ活用、業務システムなど6つのサービス |
| 導入事例 | 物流・医療・小売の3事例 |
| 開発の流れ | ヒアリングからリリース・運用までの4ステップ |
| お知らせ | ニュース一覧（お知らせ欄はここから内容を読み込みます） |
| 採用情報 | 募集職種の一覧 |
| 会社概要・お問い合わせ | 会社情報と問い合わせフォーム |

### 特徴

- スマホ・タブレット・パソコンの画面幅に対応したレスポンシブデザイン
- スクロールに合わせて各セクションがふわっと表示されるアニメーション
- OS で「視差効果を減らす」設定をしている場合はアニメーションを抑制
- 問い合わせフォームはデモ用です。必須項目のチェックのみ行い、実際には送信されません

### 外部リソース

- フォント：Google Fonts（Inter、Noto Sans JP）

インターネットに接続していない場合は、パソコンに入っている標準のフォントで表示されます。

## ブラウザで開く手順

### 方法1：ファイルをダブルクリックする

1. エクスプローラーでこのフォルダを開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザ（Edge、Chrome など）でサイトが表示されます。

### 方法2：ブラウザにドラッグ＆ドロップする

1. ブラウザを起動します。
2. `index.html` をブラウザのウィンドウにドラッグ＆ドロップします。

### 方法3：ブラウザを指定して開く

1. `index.html` を右クリックします。
2. 「プログラムから開く」から使いたいブラウザを選びます。

### 方法4：ローカルサーバーで開く（任意）

ファイルを直接開くだけで動作しますが、本番に近い環境で確認したい場合は簡易サーバーを使えます。
Python がインストールされていれば、このフォルダで次のコマンドを実行します。

```bash
python -m http.server 8000
```

ブラウザで <http://localhost:8000> を開くと表示されます。終了するときはターミナルで `Ctrl + C` を押します。

## 編集のヒント

- **お知らせの更新**：`index.html` の「お知らせ」セクション（`<ul class="news">`）を書き換えると、ナビゲーション下のお知らせ欄にも自動で反映されます。
- **配色の変更**：`<style>` 冒頭の `:root` にある色の変数（`--sky`、`--sunset` など）を変更すると、サイト全体の色が変わります。
